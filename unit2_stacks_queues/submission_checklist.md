# Grading Checklist Mapped to TODO Blocks

Use this checklist before submitting your weekly discussion.

## Code Modification Checklist
- [x] I did **not** submit the starter unchanged.
- [x] I completed every `TODO (Student)` block in the starter file.
- [x] I added additional test cases beyond the starter examples.
- [x] I improved the print statements so the output is easy to understand.
- [x] I added comments explaining important logic.

## Edge Case Checklist
- [x] I tested at least one edge case required by the starter.
- [x] I explained what happened in the output or README.
- [x] I handled empty structures, missing values, invalid input, or a comparable special case.

## Concept Understanding Checklist
- [x] My code demonstrates the required operations for the week.
- [x] My README explains how the structure or algorithm works.
- [x] My README includes at least one real-world use case or interpretation.

## Customization Checklist
- [x] I added my own example or scenario beyond the starter.
- [x] My code shows that I understand the topic rather than just running the file.

## GitHub Checklist
- [x] My weekly folder contains the Python file.
- [x] My weekly folder contains an updated README.
- [x] My GitHub repository is organized and readable.

## Discussion Checklist
- [x] I explained my design approach in the initial post of the discussion board.
- [x] I posted my GitHub repo link in the discussion board.
- [ ] I responded to at least **two classmates**.
